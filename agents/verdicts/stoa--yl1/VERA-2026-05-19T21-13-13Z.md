  - probe_p3_utf8_locale_dependency: Probe 3's `grep -nE "60. multiplier"` returns 0 matches in default Git Bash locale because `×` (U+00D7) is 2 bytes in UTF-8 (0xC3 0x97); the `.` wildcard matches 1 byte. Required workarounds: `LC_ALL=C.UTF-8 grep -nE "60. multiplier"` (then ec=0, returns line 434) OR `grep -nE "60.. multiplier"` (2-byte wildcard) OR `grep -nE "60×"` (literal). The design notes the dot-wildcard mitigation but doesn't account for multi-byte UTF-8 in the default Git Bash locale. Substantive truth: `60× multiplier` IS present at line 434 (verified via Python). The probe spec is brittle to locale settings. Recommended fix-shape for next arc: include `LC_ALL=C.UTF-8` (or equivalent PYTHONUTF8-style env) in the probe spec when grepping U+00D7 / U+00A7 / other non-ASCII canonical content.
