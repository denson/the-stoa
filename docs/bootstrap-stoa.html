The Stoa · getting set up

Set up your Stoa — what to expect.

Setting up the Stoa is a handful of one-time steps, and your assistant does the actual work — you just approve a couple of things along the way. At the end you have your own small AI team: a chief-of-staff you talk to, an orchestrator that runs the work, and a set of specialists — all remembering across sessions.

How to start. Open Claude Code Desktop and hand it this page — paste the link, or just say "set up the Stoa for me." Your assistant reads the setup instructions and drives it. You don't need git, an account, or any prior setup — that's what this installs.

What your assistant does

  1. Installs git, if your computer doesn't already have it — the tool everything else rides on.
  2. Installs beadwork (bw) — a small open-source program that gives your AI memory that survives across sessions.
  3. Downloads the Stoa and deploys your team into your AI's home folder.
  4. Creates your notes store so the team remembers your projects and decisions over time.

You okay each step as it comes; your assistant runs it. It checks what you already have first — if git's already on your machine, it skips that step.

On Windows, expect a security prompt or two

When a new tool is installed or run for the first time, Windows usually shows a warning — a "Windows protected your PC" box, or "Do you want to allow this app to make changes?" That's Windows being careful about a tool it hasn't seen before, not a sign anything's wrong.

And it isn't a leap of faith. Git is one of the most widely used tools in all of software. And beadwork is a fully open project — your assistant can read its actual source and confirm it's the genuine thing before installing. Your assistant will tell you which prompt is coming and that it's safe to allow; you click through, and you're done. (On a Mac it's similar: you may be asked for your login password once.)

What you're allowing

The whole permission surface is small: install git (if it's missing), install beadwork, download the Stoa, deploy the team's files into your AI's home folder, and create a projects folder. None of it can make purchases, send messages, or reach outside those folders.

If a step balks

Setup is where the occasional hiccup lives — a different Windows version, a tool installed in an unexpected place, a download that didn't land. If something stalls, just tell your assistant what you saw on screen. It can almost always work around it, and the steps are reversible. (This is new, and you're among the first to run it — so if anything's rough, that's useful signal, not a dead end.)

What you end up with

A running user-level Stoa team. Open a fresh Claude Code session and say "POLYBIUS" (or "chief of staff") — the chief-of-staff introduces itself, learns your name, and walks you through the rest. From there you have an AI team that holds context across sessions instead of starting cold every time.

The Stoa goes further when your assistant can see and drive your browser — open a visual walkthrough, check a page, fill a form, drive a web tool. That's the Claude in Chrome extension: a quick add from the Chrome Web Store, then you sign in with your Claude account.
